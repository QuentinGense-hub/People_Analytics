# People Analytics

Analyse de profils RH afin de déterminer le taux d'attrition dans l'entreprise.

## EDA

Analyse graphique des données récupérées afin d'avoir un premier aperçu visuel de la donnée.

## Modèle

Modèle cherchant à prédire les chances de départ d'un collaborateur. En vérité le modèle arrive à de mauvaise performance car il est difficile avec les données
fournies de réussir à prédire un comportement humain.

## Synthése finale

Résumé des observations faites.
